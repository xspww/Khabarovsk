Cronus Launcher — multi-account Roblox launcher for Windows

Run several Roblox accounts from one dashboard: queue them, launch them together, rejoin automatically after a disconnect, and keep the machine usable.

Cronus Launcher is a free, open source desktop app for playing multiple Roblox accounts on one PC. It stages accounts in a queue, sets the target Place ID, launches them at once, and rejoins the same server when a client drops or gets kicked. Performance controls cap FPS, low-graphics mode, RAM, CPU, and window layout so a handful of clients stays stable. Account cookies are encrypted on your machine with Windows DPAPI and never leave it.

What it does

Everything below runs from the local dashboard. The launcher starts a service on 127.0.0.1 and opens the desktop window — no cloud account, no upload of your sessions.

Multi-account queue

Sign in through a popup browser, one account at a time, or paste up to 50 user:pass lines in Multi mode. You complete 2FA, captcha, and passkey; the launcher captures the cookie automatically.

Automatic rejoin

Detects disconnects and kicks, then rejoins the configured Place ID and server on its own — useful for long sessions where babysitting each client is not realistic.

AFK farm sessions

Keep accounts in a game for hours while a status board shows Online, Queued, Finished, Captcha, Banned, Suspended, Locked, Recovery, and Invalid.

Performance controls

FPS limit and low-graphics mode, memory management for multi-instance sessions, automatic window layout, plus a CPU limiter and process priority applied to Roblox clients.

Lua loader for executors

Ship lua/run_in_executor.lua (in the portable zip it is Api.lua) to your executor for faster rejoin telemetry and in-game commands.

Executor and client managers

Tracks whether your executor works with the current official Roblox version, optionally relaunching and rejoining when it becomes compatible again, and installs or updates the Roblox client itself.

Download and install

Pick the standalone build for normal use, or clone the source if you want to run or modify the code.

  1. Open the Releases page.
  2. Download CronusLauncher-<version>.exe and run it.
  3. Verify the download against the SHA256 value published on the release page.
# Verify the download (PowerShell)
(Get-FileHash CronusLauncher-<version>.exe -Algorithm SHA256).Hash
Release artifacts
CronusLauncher-<version>.exe Versioned download artifact. This is the exact file name the in-app updater fetches.
CronusLauncher-<version>-portable.zip CronusLauncher.exe with a stable name (shortcuts survive in-place updates) plus Api.lua, the executor loader script.

The executable is not signed with a commercial Windows publisher certificate, so SmartScreen may warn on first run. Release builds are signed with the project release key and the updater checks that signature plus the SHA256 digest before installing anything.

Frequently asked questions

Is Cronus Launcher free?

Yes. It is free and open source under GPL-3.0. Download the standalone Windows build from the Releases page, or run it from source with Python 3.11+.

How many Roblox accounts can I launch at the same time?

The launcher sets no fixed cap — how many clients stay smooth depends on your PC. The multi-add dialog accepts up to 50 user:pass lines per import, and accounts can be queued and started together from one dashboard.

Where are my account cookies stored?

On your machine only, encrypted with Windows DPAPI, under %LOCALAPPDATA%\Cronus Launcher\data. Cookies are never sent to an external server and never committed to the repository.

Does it bypass bans or anti-cheat?

No. Cronus Launcher launches and manages accounts you already own. It does not bypass bans, security checks, or anti-cheat systems.

Do I need Python installed?

No for the release build: the .exe is standalone and only needs Windows 10/11 64-bit and Roblox Player. Running from source needs Python 3.11+.

How are updates verified?

Each release artifact is signed with the project release key, and the in-app updater verifies that signature plus the SHA256 digest before installing. Updates leave the data directory untouched.
