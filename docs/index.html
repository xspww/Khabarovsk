Cronus Launcher

ลอนเชอร์ Roblox หลายบัญชี สำหรับ Windows

คุม Roblox หลายบัญชีจากแดชบอร์ดเดียว จัดคิวไว้แล้วกดเปิดพร้อมกัน พอหลุดหรือโดนเตะระบบก็รีจอยกลับเซิร์ฟเวอร์เดิมให้เอง ปล่อย AFK farm ข้ามคืนได้ ส่วน FPS / RAM / CPU ก็ล็อกไว้ไม่ให้เครื่องอืด และ cookie ทุกบัญชีเข้ารหัสด้วย Windows DPAPI เก็บไว้ในเครื่องคุณเท่านั้น

ดาวน์โหลดเลย! → Discord

  • .exe ใช้ได้เลย ไม่ต้องลง Python
  • cookie เข้ารหัสในเครื่อง (DPAPI)
  • อัปเดตตรวจลายเซ็น + SHA256
  • ไม่เกี่ยวข้องกับ Roblox Corporation

ทำอะไรได้บ้าง

ทุกอย่างสั่งจากแดชบอร์ดในเครื่อง ตัวลอนเชอร์เปิด service ที่ 127.0.0.1 แล้วเปิดหน้าต่างให้เอง ไม่มีบัญชีคลาวด์ ไม่มีข้อมูลเซสชันถูกส่งออกไปข้างนอก

จัดคิวหลายบัญชี

ล็อกอินผ่านป๊อปอัพทีละบัญชี หรือวาง user:pass ในโหมด Multi ได้ถึง 50 บรรทัด ส่วน 2FA กับ captcha และ passkey คุณกดเองในป๊อปอัพ แล้วตัวโปรแกรมดึง cookie ให้อัตโนมัติ

รีจอยอัตโนมัติ

พอไคลเอนต์หลุดหรือโดนเตะ ระบบพากลับเข้า Place ID กับเซิร์ฟเวอร์ที่ตั้งไว้ให้เอง เหมาะกับเซสชันยาวๆ ที่นั่งเฝ้าทีละจอไม่ไหว

ปล่อย AFK farm

ปล่อยบัญชีค้างในเกมได้เป็นชั่วโมง ระหว่างนั้นบอร์ดสถานะบอกไว้ครบทั้ง Online Queued Finished Captcha Banned Suspended Locked Recovery และ Invalid

คุมประสิทธิภาพ

ล็อก FPS โหมดกราฟิกต่ำ จัดการ RAM สำหรับเซสชันหลายจอ จัดเลย์เอาต์หน้าต่างให้อัตโนมัติ พร้อมตัวจำกัด CPU และตั้ง priority ให้ไคลเอนต์ Roblox

Lua loader สำหรับ executor

เอา lua/run_in_executor.lua ไปรันใน executor (ไฟล์ zip แบบพกพาแถมมาในชื่อ Api.lua) ช่วยให้ส่ง telemetry กับสั่งงานในเกมได้ไวขึ้น

ตัวจัดการ executor และไคลเอนต์

ตามดูว่า executor ที่คุณใช้ยังทำงานกับ Roblox เวอร์ชันทางการไหม เปิด auto-relaunch ไว้ก็ปิดแล้วเปิดใหม่ให้ พร้อมรีจอยกลับเข้าเกม และติดตั้งหรืออัปเดตตัวเกมให้ด้วย

ดาวน์โหลดและติดตั้ง

ใช้ไฟล์ .exe จากหน้า Releases ก็พอ ถ้าอยากรันจากซอร์สหรือแก้โค้ดเองก็โคลน repo ได้เลย

  1. เปิดหน้า Releases
  2. โหลด CronusLauncher-<version>.exe แล้วเปิดได้เลย
  3. เทียบค่า SHA256 ที่ได้กับค่าที่ประกาศไว้บนหน้า release
# ตรวจไฟล์ที่โหลดมา (PowerShell)
(Get-FileHash CronusLauncher-<version>.exe -Algorithm SHA256).Hash
ไฟล์ในหน้า release CronusLauncher-<version>.exe — ไฟล์ดาวน์โหลดตามเวอร์ชัน และเป็นชื่อที่ตัวอัปเดตในแอปโหลดตรงตัว
ไฟล์ zip แบบพกพา CronusLauncher-<version>-portable.zip — CronusLauncher.exe ที่ใช้ชื่อคงเดิม (ชอร์ตคัตไม่หลุดตอนอัปเดตแบบแทนที่ไฟล์) พร้อม Api.lua สคริปต์ loader สำหรับ executor

ไฟล์ .exe ไม่ได้เซ็นด้วยใบรับรอง publisher เชิงพาณิชย์ พอเปิดครั้งแรก SmartScreen อาจเตือน ตัวไฟล์ release เซ็นด้วยคีย์ของโปรเจกต์ และตัวอัปเดตจะตรวจลายเซ็นกับ SHA256 ก่อนติดตั้งทุกครั้ง

สิ่งที่ต้องมี

ของบังคับจริงมีอย่างเดียวคือ Windows 10/11 รุ่น 64-bit ส่วนที่เหลือสำหรับคนที่รันจากซอร์ส

ระบบปฏิบัติการWindows 10 หรือ Windows 11 รุ่น 64-bit
รันไทม์ (ตัว release)ไม่ต้องลงเพิ่ม ไฟล์ .exe จากหน้า Releases พร้อมใช้
รันไทม์ (รันจากซอร์ส)Python 3.11 ขึ้นไป และ pip install -r requirements.txt
ตัวเกมลง Roblox Player ไว้บนเครื่องเดียวกัน
WebView2Evergreen Runtime (ถ้ายังไม่มี แอปจะถามก่อนแล้วโหลดให้)
เบราว์เซอร์Chrome หรือ Edge ที่ลงไว้แล้ว สำหรับป๊อปอัพตอนล็อกอิน

ข้อมูลตอนรันอยู่ที่ %LOCALAPPDATA%\Cronus Launcher\data เปลี่ยนที่เก็บได้ด้วย env CRONUS_USER_ROOT ถ้าไม่มี %LOCALAPPDATA% จะใช้ ~/.cronus_launcher แทน

คำถามที่เจอบ่อย

Cronus Launcher ใช้ฟรีไหม

ใช้ฟรี และเป็นโอเพนซอร์สภายใต้สัญญาอนุญาต GPL-3.0 โหลดไฟล์ .exe สำหรับ Windows จากหน้า Releases หรือจะรันจากซอร์สด้วย Python 3.11 ขึ้นไปก็ได้

เปิด Roblox พร้อมกันได้กี่บัญชี

ตัวลอนเชอร์ไม่ได้ล็อกจำนวนไว้ ตกลงอยู่ที่สเปกเครื่องคุณ หน้าต่างเพิ่มบัญชีแบบ Multi รับได้ถึง 50 บรรทัดต่อครั้ง แล้วจัดคิวเปิดพร้อมกันจากแดชบอร์ดได้

cookie ของบัญชีเก็บไว้ที่ไหน

เก็บในเครื่องคุณเอง เข้ารหัสด้วย Windows DPAPI ที่ %LOCALAPPDATA%\Cronus Launcher\data ไม่ส่งออกไปเซิร์ฟเวอร์ภายนอก และไม่ถูกคอมมิตลง repo

ข้ามแบนหรือหลบระบบป้องกันเกมไหม

ไม่ ตัวโปรแกรมแค่เปิดและจัดการบัญชีที่คุณมีอยู่แล้ว ไม่ได้ข้ามแบน ไม่ได้หลบระบบตรวจสอบหรือระบบป้องกันใดๆ

ต้องลง Python ไหม

ไม่ต้องสำหรับไฟล์ release เพราะ .exe ใช้ได้เลย ขอแค่ Windows 10/11 64-bit กับ Roblox Player ส่วนการรันจากซอร์สต้องใช้ Python 3.11 ขึ้นไป

อัปเดตตรวจอะไรก่อนติดตั้ง

ไฟล์ release เซ็นด้วยคีย์ของโปรเจกต์ ตัวอัปเดตในแอปจะตรวจลายเซ็นกับค่า SHA256 ก่อนติดตั้ง และไม่แตะโฟลเดอร์ข้อมูลของคุณเลย
